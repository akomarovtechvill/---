# IPLAYSMART — концепция эксплуатации

Концепция эксплуатации пиццемата IPLAYSMART по образцу «РТК: Концепция эксплуатации» и интерактивная панель режимов по образцу `rtk-modes-panel`. Черновик, ревизия 00 от 03.11.2026.

| Путь | Содержимое |
|---|---|
| `model/ips-model.js` | Единый источник: режимы, переходы, признаки, причины, команды, заказ, параметры, сценарии, решения, вопросы |
| `IPS_ Концепция эксплуатации.docx` | Документ, собирается из модели |
| `panel/index.html` | Панель режимов, один файл, открывается в браузере |
| `panel/escalation.html` | Панель эскалации инцидентов (приложение Д), данные — `M.esc` в модели |
| `tools/fill_escalation.py` | Заполняет приложение Д в docx, не трогая остальной текст |
| `panel/src/` | Страница, стили (из rtk-modes-panel) и код панели |
| `panel/scheme.png` | Схема режимов для рисунка 1 в документе |
| `tools/gen_docx.js` | Генератор документа |

## Сборка

Правки вносятся в `model/ips-model.js`, затем:

```bash
node panel/build.js
"/c/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" --headless=new --hide-scrollbars --force-device-scale-factor=2 --window-size=1300,800 --screenshot=panel/scheme.png "file:///<путь>/panel/index.html#scheme"
npm install docx@9.5.1
node tools/gen_docx.js
```

Оглавление документа обновляется при открытии в Word (обновить поля).

С 05.11.2026 документ правится вручную в Word, поэтому `tools/gen_docx.js` больше не запускается — он перезапишет правки. Приложение Д обновляется отдельно:

```bash
python tools/fill_escalation.py "IPS_ Концепция эксплуатации.docx" "IPS_ Концепция эксплуатации.docx"
```

Схема (координаты блоков и линий) задана в `panel/src/app.js` (`NODES`, `COMPS`, `EDGES`). Новый переход в модели нужно добавить и туда.

В документах нет ключей, паролей и служебных кодов: они хранятся в хранилище секретов.
